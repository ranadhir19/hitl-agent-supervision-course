# Capstones — stages of the simulation, made gradable

Each capstone is one stage of the course's continuous banking-operations
simulation, packaged as a gradable project: a brief, a provided agent and
data, starter material, a published rubric, and a reference solution released
after the attempt window. The bank and its customers are fictional; the
supervision artefacts you produce are the real ones used in the job.

**Universal deliverables discipline:** every capstone is documented as you go —
the artefacts below are the submission, not a write-up after the fact.
**Universal feature:** every capstone carries **injected failures** — faults
introduced deliberately, without warning in the materials, because detecting
them is the skill being graded. A documented 70% beats an undocumented 100%.
